🌟 Estructura Gherkin

Gherkin usa palabras clave simples para describir el comportamiento:

# Ejemplo de escenario Gherkin Feature: Login de usuarios Scenario: Usuario inicia sesión correctamente Given que estoy en la página de login When ingreso mis credenciales válidas Then debo ver el dashboard principal
✅ Regla de Oro: Given = Contexto | When = Acción | Then = Resultado Esperado

🔧 ¿Cómo funciona Cucumber?

Cucumber lee tus archivos .feature y los conecta con código Java:

// Step Definition en Java @Given("que estoy en la página de login") public void estoyEnLogin() { actor.attemptsTo(Open.browserOn().the(LoginPage.class)); } @When("ingreso mis credenciales válidas") public void ingresoCredenciales() { actor.attemptsTo(LoginUI.withCredentials(user, pass)); }

🎭 Los 4 Pilares de Screenplay

Actor

El Protagonista

Es quien ejecuta las acciones. Puede ser un usuario, un admin, etc.

Actor.called("Juan")
Ability

La Habilidad

Lo que el actor puede hacer (navegar, usar API, etc.)

can(BrowseTheWeb.with(...))
Task

La Tarea

Lo que el actor quiere lograr (iniciar sesión, comprar)

actor.attemptsTo(Login.with(...))
Question

La Pregunta

Lo que el actor quiere saber (¿está logueado?)

actor.asksFor(Title.isEqualTo(...))

📸 Los Reportes de Serenity

Serenity genera reportes automáticos con screenshots, HTML y trazabilidad completa.

️ Prohibido: Usar Thread.sleep() en tus tests. Es como poner una venda en los ojos del test.

⏱️ Waits Inteligentes

// MAL - No uses esto Thread.sleep(5000); // ✅ BIEN - Usa waits de Serenity actor.attemptsTo(WaitUntil.the(LOGIN_BUTTON, isClickable())); actor.attemptsTo(WaitUntil.the(DASHBOARD, isVisible()));
