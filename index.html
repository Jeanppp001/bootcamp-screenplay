    ESCENA 1 · INT. GHERKIN — DÍA

    El lenguaje del negocio

    Antes de escribir una sola línea de Java, hay que aprender a describir el comportamiento en un idioma que negocio, QA y desarrollo puedan leer sin traducir nada.

    ¿Qué es Gherkin?Primer contacto con el lenguaje, en español.
    Introducción a Gherkin (Parte 1)El camino hacia Cucumber, explicado paso a paso.
    Por qué importa: Gherkin no existe para que el código se vea bonito. Existe para que un Product Owner, un QA y un desarrollador lean el mismo archivo .feature y entiendan exactamente lo mismo.

    Estructura de un escenario

    # Ejemplo de escenario Gherkin Feature: Login de usuarios Scenario: Usuario inicia sesión correctamente Given que estoy en la página de login When ingreso mis credenciales válidas Then debo ver el dashboard principal
    Regla de oro: Given = contexto · When = acción · Then = resultado esperado.

    ESCENA 2 · INT. CUCUMBER — DÍA

    Conectando Gherkin con el código

    Cucumber es el intérprete: toma cada línea del .feature y la conecta con un método Java real llamado step definition.

    Tutorial de Cucumber con Java — Capítulo 1: Hola mundoPrimer capítulo de la serie, en español. El mismo canal continúa con capítulos 2, 3... busca su nombre exacto en YouTube para seguir la serie completa.

    Anatomía de un step definition

    @Given("que estoy en la página de login") public void estoyEnLogin() { actor.attemptsTo(Open.browserOn().the(LoginPage.class)); } @Then("debo ver el dashboard principal") public void deboVerDashboard() { assertThat(actor.asksFor(Text.of(DASHBOARD_TITLE))).isEqualTo("Dashboard"); }

    Reto: completa el step definition

    ESCENA 3 · INT. SCREENPLAY — NOCHE

    El patrón dorado: actores, tasks y questions

    Screenplay modela cada prueba como una obra: un actor con habilidades, que intenta tareas y luego pregunta cosas sobre el resultado.

    Curso Serenity BDD / Screenplay Web en EspañolPlaylist completa: configuración, tasks, questions y assertions con el patrón Screenplay.

    Recurso extra: si además necesitas probar APIs, busca en YouTube "Curso Serenity BDD | Screenplay Rest en Español", del mismo autor.

    Los 4 pilares de Screenplay

    ACTOR

    El protagonista

    Quien ejecuta las acciones dentro de la prueba.

    Actor.called("Juan")
    ABILITY

    La habilidad

    Lo que el actor puede hacer (navegar, llamar una API...).

    can(BrowseTheWeb.with(driver))
    TASK

    La tarea

    Lo que el actor quiere lograr, paso a paso.

    actor.attemptsTo(Login.with(user, pass))
    QUESTION

    La pregunta

    Lo que el actor quiere saber, para poder afirmarlo.

    actor.asksFor(Title.isEqualTo("Dashboard"))

    Reto: crea una task de login
